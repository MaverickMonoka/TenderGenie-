# TenderGenie AI™

Africa's Tender Intelligence & Procurement Network.

## Core workflow
Tender Radar → Qualification → Document Intelligence → QS/BOQ Estimating → Compliance → Proposal → Tender Room → Submission → Award/Handover.

## Architecture
Next.js + TypeScript. Supabase will provide authentication, PostgreSQL data and private document storage. AI/document processing stays server-side. Hosting is provider-independent.

## QS commercial rule
TenderGenie must not silently invent rates. Material, labour, plant, subcontract and commercial inputs must be traceable to an approved rate source, supplier quotation, historical company rate, calculation or explicit estimator assumption.
